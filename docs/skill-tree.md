# 스킬 트리 & 업그레이드 정보

## 기본 규칙

- 스킬은 틱 단위로 구매한다. 정해진 틱 수를 모두 채우면 1레벨이 오른다.
- 1레벨에 필요한 틱 수는 스킬마다 다르다. 아래 상세의 "틱/레벨" 항목 참고.
- 총 스킬은 공격력을 제외한 모든 스킬 레벨의 합이다. 일부 스킬은 총 스킬이 일정 이상이어야 구매할 수 있다.
- 공격력 레벨이 오르면 무기 외형이 다음 단계로 바뀐다. 무기 목록은 `game-design.md` 참고.

---

## 그룹 구조

3개 그룹으로 나뉘며, 위에서 아래로 선행 스킬이 연결된다.

### 무기 그룹
```
          [공격력]
          /      \
  [공격 속도]  [공격 범위]
      |              |
  [치명타 확률]  [몬스터 피해]
      |
  [치명타 피해]
```

### 수확 그룹
```
          [풀 밀도]
          /      \
  [풀 등급]  [공격 개수]
      |              |
  [황금풀 확률]  [수집 범위]
      |
  [황금풀 보상]
```

### 탐험 그룹
```
          [이동 속도]
           /      \
  [세션 시간]  [상자 확률]
           \      /
         [분노 속도]
```

분노 속도는 세션 시간과 상자 확률 중 하나만 Lv.1 이상이면 열린다.

## 스킬 상세

### 공격력
- **틱/레벨:** 5틱, 최대 Lv.9, 총 45틱
- **효과:** 공격력 증가
- **공식:** Lv.1~3: +1/틱, Lv.4~5: +2/틱, Lv.6~7: +3/틱, Lv.8~9: +4/틱
- **범위:** 1 → 106

### 공격 속도
- **틱/레벨:** 5틱, 최대 Lv.6, 총 30틱
- **효과:** 공격 간격 감소
- **공식:** `0.7 - 틱 × 0.02`
- **범위:** 0.70초 → 0.10초

### 공격 범위
- **틱/레벨:** 5틱, 최대 Lv.8, 총 40틱
- **효과:** 풀 베기 반경 증가
- **공식:** `60 + 틱 × 7`
- **범위:** 60 → 340

### 공격 개수
- **틱/레벨:** 3틱, 최대 Lv.5, 총 15틱
- **효과:** 한 번에 베는 풀의 개수 증가
- **공식:** 레벨별 틱당 증가량이 Lv.1: +1, Lv.2: +2, Lv.3: +3, Lv.4: +4, Lv.5: +5
- **범위:** 1개 → 46개

### 치명타 확률
- **틱/레벨:** 5틱, 최대 Lv.4, 총 20틱
- **효과:** 공격 시 치명타 발동 확률
- **공식:** `틱 × 5%`
- **범위:** 0% → 100%

### 치명타 피해
- **틱/레벨:** 5틱, 최대 Lv.5, 총 25틱
- **효과:** 치명타 발동 시 데미지 배율
- **공식:** `120% + 틱 × 10%`
- **범위:** 120% → 370%

### 몬스터 피해
- **틱/레벨:** 5틱, 최대 Lv.7, 총 35틱
- **효과:** 몬스터에 대한 추가 피해 배율
- **공식:** `100% + 틱 × 10%`
- **범위:** 100% → 450%

### 풀 밀도
- **틱/레벨:** 5틱, 최대 Lv.8, 총 40틱
- **효과:** 구획당 풀 개수 증가
- **공식:** 레벨별 틱당 증가량이 Lv.1: +1, Lv.2: +2, ..., Lv.8: +8
- **범위:** 1개 → 181개

### 풀 등급
- **틱/레벨:** 8틱, 최대 Lv.8, 총 64틱
- **효과:** 높은 등급 풀 등장 확률 증가
- **방식:** 홀수 레벨은 다음 등급 50%까지, 짝수 레벨은 다음 등급 100%까지
- **등급:** 새싹 → 잔디 → 여린풀 → 강한풀 → 초강풀

### 황금풀 확률
- **틱/레벨:** 2틱, 최대 Lv.5, 총 10틱
- **효과:** 황금풀 등장 확률. 투자하지 않으면 황금풀이 나오지 않는다.
- **공식:** `틱 × 0.1%`
- **범위:** 0% → 1.0%

### 황금풀 보상
- **틱/레벨:** 5틱, 최대 Lv.5, 총 25틱
- **효과:** 황금풀 코인 보상 증가. 기본 보상은 100원
- **공식:** 틱마다 복리로 증가. Lv.1 구간 ×1.10, Lv.2 ×1.11, Lv.3 ×1.12, Lv.4 ×1.13, Lv.5 ×1.14
- **범위:** 100원 → 1,697원

### 이동 속도
- **틱/레벨:** 6틱, 최대 Lv.5, 총 30틱
- **효과:** 플레이어 기본 이동 속도
- **공식:** `300 + 틱 × 10`
- **범위:** 300 → 600

### 세션 시간
- **틱/레벨:** 3틱, 최대 Lv.5, 총 15틱
- **효과:** 세션 시간 증가
- **공식:** `45 + 틱 × 3`
- **범위:** 45초 → 90초

### 수집 범위
- **틱/레벨:** 5틱, 최대 Lv.6, 총 30틱
- **효과:** 코인 자동 수집 범위
- **공식:** `50 + 틱 × 7`
- **범위:** 50 → 260

### 상자 확률
- **틱/레벨:** 5틱, 최대 Lv.5, 총 25틱
- **효과:** 새 청크 진입 시 상자 스폰 확률
- **공식:** `틱 × 0.2%`
- **범위:** 0% → 5%

### 분노 속도
- **틱/레벨:** 4틱, 최대 Lv.4, 총 16틱
- **효과:** 몬스터분노 게이지 증가 배율
- **공식:** `100% + 틱 × 15%`
- **범위:** 100% → 340%

## 업그레이드 비용

- 스킬마다 레벨별 비용표가 따로 있다.
- 같은 레벨 안에서는 틱을 살 때마다 비용이 일정하게 오른다.
- 이동 속도 Lv.1은 첫 진입용으로 틱당 1~3원 수준으로 매우 싸다.

---

## 파워업 중첩

아래 스킬은 세션 중 파워업 효과가 스킬 수치에 곱해지거나 덮어쓴다.
- 공격 속도, 공격 범위, 수집 범위, 이동 속도: 파워업 배율이 곱해짐
- 치명타 확률: 치명타 폭주 중에는 100%
- 치명타 피해: 치명타 폭주 중에는 2배

나머지 스킬은 파워업의 영향을 받지 않는다.
